# Guía de Laboratorio del Episodio 89: Las taquillas del destino

## Ejecución por Línea de Comandos
```bash
bin/episodio 89
bin/episodio 89_las_taquillas_del_destino
```

- `2`: Error de precondición o fallo de simulación.
