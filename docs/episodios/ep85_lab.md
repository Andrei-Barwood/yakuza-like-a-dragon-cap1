# Guía de Laboratorio del Episodio 85: El farol en Kamurocho

## Ejecución por Línea de Comandos
```bash
bin/episodio 85
bin/episodio 85_el_farol_en_kamurocho
```

## Códigos de Salida CLI
- `0`: Simulación técnica completada con éxito.
- `2`: Error de precondición o fallo de simulación.
- `3`: Parámetros inválidos.

## Validación Automatizada
```bash
bundle exec rake test TEST=test/test_scenario_ep85.rb
```
